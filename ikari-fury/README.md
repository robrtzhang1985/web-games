# 怒之格斗 IKARI FURY 3v3

**50 人**乱斗街机格斗游戏，单文件网页（`index.html`，约 1MB，30 名角色的 AI 生成立绘已内嵌），零依赖，手机竖/横屏 + 微信内置浏览器适配。**同人致敬粉丝作品：角色为 AI 生成原创立绘，与 SNK / 拳皇等官方无关。**

## 玩法（3v3 车轮战）

- 每队 3 人按顺序上场，打倒一个换下一个，**全灭判负**
- **不限时**：打到血量清零为止
- **胜者血量继承**：赢的角色保留血量进入下一局，至少恢复到一半
- **电脑无限升级**：电脑每被打倒一人自动升一级（反应/攻速/防御全面提升）
- **残血破损**：血量低于 40% 时掉落头盔/头巾/帽子等装备（掉在地上），姿态变带伤踉跄、掉碎屑
- **KO 演出**：全场暗化 + 聚光灯打在胜者身上，胜者庆祝、败者躺地半透明
- **6 大随机场景**：黄昏军营 · 阳光海滩 · 樱花道场 · 蓝天都市 · 翠竹林 · 白昼竞技场，每次开战随机
- **场边助威**：未出场的队友站在背景两侧观战、蹦跳打气，随机冒"加油！/上啊！/必杀！"气泡
- 防御：按住后方向；蹲下可躲飞行道具；防御槽空会眩晕（防御崩坏）
- 能量满 100：**超必杀**（每人专属）或通用**十字光线**（奥特曼式光线）
- **全员飞行**：任何角色跳起后再按一次"上"即起飞，空中可飘移；约 3 秒后坠落——自己掉 8 点血，砸中对手造成 22+ 大伤害

## 操作

**手机触控**：左下摇杆移动（双击同方向=疾跑，跳起后再推上=飞行角色起飞）· 右下五键：轻 / 重 / 杀 / 超 / 光

**键盘玩家1**：`A`/`D` 移动（双击=疾跑）、`W` 跳、`S` 蹲、`J` 轻击、`K` 重击、`L` 必杀、`U` 超必杀、`I` 十字光线（超/光需能量满）

**键盘玩家2（双人对战）**：方向键 + `,` 轻 `.` 重 `/` 必杀 `'` 超 `[` 光线

## 模式

- **街机：决战暗影队**——选 3 人 vs 暗影镜像队（紫色版全员），电脑无限升级
- **双人对战**——同屏 3v3，两人各选 3 人

## 技术说明

- 纯 HTML/CSS/JS 单文件；30 角色 × 3 姿势立绘由 Agnes AI 文生图生成（纯绿背景→程序抠图→列密度谷底切片→量化压缩→base64 内嵌）
- 战斗系统：帧数据（启动/判定/收招）、判定框、投技演出、多段技、飞行道具、光线、雷电、流星俯冲、连击计数、counter、防御崩坏、无限等级 AI
- WebAudio 合成音效，可静音
- 文件含 `window.__fury` 调试钩子（自动化测试用）：`start/state/press/hold/setHP/setMeter`
- 立绘再生成流程：`art/` 下放 `<id>_sheet.png`（纯绿背景三姿势横排）→ `python3 tools/process_sprites.py` → `python3 tools/inject_sprites.py`
