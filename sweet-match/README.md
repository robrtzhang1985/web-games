# 甜心消消乐 💗

粉色梦幻风的糖果三消小游戏，单文件网页（`index.html`），零依赖、无需安装，手机竖屏 + 微信内置浏览器适配。

## 玩法

- 点一点或划一划，交换相邻糖果，3 个一样就会消除
- **4 连** → 条纹糖（清一整行/列）
- **L 型 / T 型** → 小炸弹（轰掉一圈）
- **5 连** → 彩虹糖（和任意糖果交换，全消那一色）
- 每关 22 步，步数用完前达到目标分就过关，星级按 1x / 1.3x / 1.6x 目标分评定
- 过关进度自动保存在手机上（localStorage），下次打开接着玩

## 怎么发给微信好友

### 方式一：发网页链接（体验最好，推荐）

把 `index.html` 部署成链接，微信里点开直接玩：

- **Netlify Drop（最简单）**：打开 https://app.netlify.com/drop ，把 index.html 拖进去，几秒后得到一个链接，发给好友即可（国内访问偶尔不稳）
- **GitHub Pages**：建一个仓库上传 index.html，Settings → Pages 开启即可得到 `https://用户名.github.io/仓库名/`（国内大多可直连）

### 方式二：直接发文件

把 `index.html` 通过微信发送（如文件传输助手/群聊）：

- **安卓**：收到的文件用 QQ浏览器 / 系统浏览器打开即可玩
- **iPhone**：微信里长按文件 →「用其他应用打开」→ 存到「文件」→ 用 Safari 打开

### 方式三：同 WiFi 手机试玩

电脑上在本目录执行（或保持当前已运行的服务）：

```bash
python3 -m http.server 8123 --bind 0.0.0.0
```

手机连同一 WiFi，微信或浏览器打开：`http://<电脑局域网IP>:8123/`（IP 用 `ipconfig getifaddr en0` 查看）

## 技术说明

- 纯 HTML + CSS + 原生 JS，糖果图标为内嵌 SVG 手绘（爱心/星星/花朵/蝴蝶结/小猫/四叶草）
- 音效由 WebAudio 实时合成，无外部资源，可一键静音
- 文件内含 `window.__sxk` 调试钩子，仅供自动化测试使用，不影响游戏
